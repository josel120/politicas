# Políticas

Políticas legales públicas (privacidad, términos y eliminación de cuenta) de todas mis apps y webs, servidas
gratis con GitHub Pages en https://josel120.github.io/politicas/.

Estructura: una carpeta por producto (`<producto>/privacidad/`, `<producto>/eliminar-cuenta/`, …). Cada página
es `index.md` (Jekyll la convierte en HTML) o `index.html`. La fuente de verdad de cada texto vive en el repo de
su app; esta es la copia publicada. Al cambiarla allí, cópiala aquí en el mismo commit de release.
